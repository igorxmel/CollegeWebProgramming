## Быстрый старт

Основной способ, открыть страницу в браузере и нажать `F12`, вывод всех заданий будет на
вкладке Console:

```bash
start "" "Solution/index.html"
```

То же самое через локальный сервер, из корня репозитория:

```bash
cd "Task 2nd JavaScript Basics/Solution" && python -m http.server 8000
```

Страница будет доступна по адресу http://localhost:8000, остановка сервера по `Ctrl+C`.

Отдельное задание можно запустить в Node.js, браузер для этого не нужен:

```bash
node "Task 2nd JavaScript Basics/Solution/js/05-price-increase.js"
```

## Теоретическая часть

### Подключение JavaScript

Код можно писать прямо в HTML внутри тега `<script>`, но нормальный способ это отдельный
файл:

```html
<script src="script.js"></script>
```

Тег ставится перед закрывающим `</body>`. К моменту его выполнения браузер уже разобрал
разметку, поэтому скрипт видит все элементы страницы. Отдельный файл отделяет структуру от
логики и кешируется браузером.

### Переменные

В языке три ключевых слова для объявления переменных.

`const` объявляет константу. Значение задаётся сразу и переприсвоить его нельзя, область
видимости блочная. Запрет распространяется на саму переменную, а не на содержимое: если в
константе лежит объект или массив, менять их свойства и элементы можно.

```js
const user = { name: "Анна" };
user.age = 25;             // так можно
// user = { name: "Пётр" }; // а так уже ошибка
```

`let` объявляет изменяемую переменную с блочной областью видимости. Присваивать новое
значение можно сколько угодно, но объявить второй раз с тем же именем в той же области
нельзя.

`var` устарел. У него функциональная область видимости, а не блочная, поэтому переменная,
объявленная внутри `if`, остаётся доступной за его пределами. Плюс `var` всплывает:
обращение к переменной до объявления возвращает `undefined` вместо ошибки.

По умолчанию берут `const`, `let` только там, где значение действительно переприсваивается,
`var` не используют вообще.

### Условные конструкции

Условия выбирают, какая ветка кода выполнится:

```js
let age = 20;

if (age >= 18) {
    console.log("Доступ разрешён");
} else {
    console.log("Доступ запрещён");
}
```

Кроме `if...else` есть цепочка `else if`, тернарный оператор `условие ? a : b` для коротких
выражений и `switch` для сравнения одного значения с набором вариантов.

### Циклы

Классические циклы: `for` со счётчиком, когда количество повторений известно заранее,
`while` с проверкой условия перед выполнением тела и `do...while` с проверкой после, поэтому
тело гарантированно выполняется хотя бы раз.

Циклы для перебора коллекций: `for...of` идёт по значениям массива или строки, `for...in` по
ключам объекта. Путать их не стоит, `for...in` по массиву вернёт индексы в виде строк, а не
элементы.

Отдельно стоят методы массивов, которые заменяют цикл: `forEach()` выполняет функцию для
каждого элемента, `map()` строит новый массив из результатов, `filter()` оставляет только
подходящие элементы. Код с ними короче, но `break` в них не работает.

Ход цикла меняют операторы `break` (выйти совсем) и `continue` (пропустить текущую
итерацию).

### Функции

Функция это именованный блок кода, который принимает аргументы, что-то делает и может
вернуть результат через `return`. Если `return` не написан, функция возвращает `undefined`.

```js
function greet(name) { return `Привет, ${name}!`; }   // Function Declaration
const greet2 = function (name) { return name; };       // Function Expression
const greet3 = (name) => `Привет, ${name}!`;           // стрелочная функция
```

Первый вариант всплывает, то есть функцию можно вызвать до строки объявления. Второй и
третий доступны только после выполнения строки с присваиванием. Стрелочные функции короче и
не имеют собственного `this`, они берут его из внешней области, поэтому их удобно
использовать как коллбэки.

Есть параметры по умолчанию (`function f(a, b = 1)`), rest-параметры (`function f(...args)`,
все аргументы собираются в массив), замыкания (функция помнит переменные внешней области
даже после её завершения) и рекурсия.

### Объекты

Объект это набор пар ключ-значение. Значением может быть что угодно, включая функцию, тогда
её называют методом.

```js
const user = {
    name: "Иван",
    age: 25,
    sayHello() {
        console.log(`Привет, я ${this.name}`);
    }
};
```

К свойствам обращаются точкой (`user.name`), когда ключ известен заранее, или квадратными
скобками (`user["name"]`, `user[key]`), когда ключ лежит в переменной или содержит символы
вроде пробела и дефиса. Свойство добавляется присваиванием, удаляется оператором `delete`,
наличие ключа проверяется оператором `in`. Внутри метода `this` указывает на сам объект.

## Ответы на вопросы

**1. Для чего используется JavaScript?**

Это язык программирования, который делает страницу живой. В браузере он обрабатывает
действия пользователя, меняет содержимое и стили элементов, проверяет формы, показывает
модальные окна, обменивается данными с сервером без перезагрузки. HTML отвечает за
структуру, CSS за оформление, JavaScript за поведение. Вне браузера он тоже работает,
например на Node.js для серверной части.

**2. В чём различие между `let`, `const` и `var`?**

`const` создаёт константу: инициализация обязательна сразу, переприсвоить нельзя, область
видимости блочная. Содержимое объекта или массива в константе при этом менять можно.

`let` создаёт изменяемую переменную с блочной областью видимости, повторное объявление в той
же области запрещено.

`var` устарел. Его область видимости функциональная, он всплывает и допускает повторное
объявление, из-за чего с ним легко получить неочевидные ошибки.

**3. Для чего применяются условные конструкции?**

Чтобы программа выбирала разные действия в зависимости от данных. Проверка возраста, наличия
товара, правильности заполнения формы, прав доступа: всё это `if...else`, `switch` и
тернарный оператор.

**4. Какие циклы существуют в JavaScript?**

`for` со счётчиком, `while` с предусловием, `do...while` с постусловием, `for...of` для
перебора значений массивов и строк, `for...in` для перебора ключей объекта. Как альтернатива
циклам используются методы массивов `forEach()`, `map()`, `filter()`, `reduce()`, `some()`,
`every()`.

**5. Что такое функция?**

Блок кода под отдельным именем, который можно вызывать сколько угодно раз с разными
аргументами. Функция принимает параметры, выполняет инструкции и возвращает результат через
`return`. Она избавляет от копирования одного и того же кода и разбивает программу на
понятные части. В JavaScript функции это объекты первого класса: их можно хранить в
переменных, передавать аргументами и возвращать из других функций.

**6. Что такое массив?**

Упорядоченный список значений под одним именем. Доступ к элементам идёт по числовому
индексу, нумерация начинается с нуля, количество элементов лежит в свойстве `length`. В
одном массиве могут храниться данные разных типов, включая другие массивы и объекты. Для
работы с ним есть `push`, `pop`, `shift`, `unshift`, `slice`, `splice`, `map`, `filter`,
`find`, `sort` и другие методы.

**7. Для чего используется метод `push()`?**

Добавляет один или несколько элементов в конец массива и возвращает новую длину. Исходный
массив при этом изменяется, поэтому `push()` работает и с массивом, объявленным через
`const`. Для добавления в начало используется `unshift()`.

**8. Для чего используется метод `map()`?**

Создаёт новый массив той же длины, применяя переданную функцию к каждому элементу
исходного. Исходный массив не меняется. Типичное применение это пересчёт значений, как в
пятом задании с наценкой 20%, или преобразование массива объектов в массив нужных полей.
Если новый массив не нужен, вместо `map()` берут `forEach()`.
