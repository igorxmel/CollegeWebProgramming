# ПР №15. Приём и обработка заявок

В лендинг Dream Sneakers добавлены отправка заявок и панель обработки. Покупатель оставляет контакты, выбирает тему и пишет сообщение. Администратор входит в /admin, находит заявку, редактирует поля, меняет статус или удаляет запись.

## Как запустить

Нужны Node.js 22.12 или новее и MySQL. На колледжном ПК открыть phpMyAdmin
в Open Server Panel и выполнить Solution/schema.sql на вкладке SQL.
Скрипт создаёт необходимые таблицы в dream_sneakers.

В папке Solution скопировать .env.example в .env. Указать пользователя,
пароль и порт MySQL из Open Server Panel. Задать пароль ADMIN_PASSWORD
для входа в панель и случайный JWT_SECRET длиной от 32 символов.

~~~powershell
npm ci
npm run server
~~~

В другом окне, из той же папки:

~~~powershell
npm run dev
~~~

Открыть адрес Vite. Панель заявок находится на /admin. Для проверки сборки
выполнить npm run build.

## Проверка

Отправить заявку с номером 89001234567, открыть /admin, найти её по почте, установить «В работе». При отклонении заполнить причину, при удалении подтвердить действие.

## Контрольные вопросы

1. **Для чего используются пользовательские формы?** Форма собирает данные покупателя и передаёт их приложению.
2. **Что такое валидация данных?** Валидация проверяет обязательность, формат и допустимые значения полей.
3. **Чем отличается клиентская валидация от серверной?** Клиент показывает ошибки сразу. Сервер повторяет проверку перед записью.
4. **Для чего применяются маски ввода?** Маска приводит номер телефона к одному формату во время ввода.
5. **Как передать данные формы на сервер с помощью Fetch API?** Вызвать fetch с POST, заголовком Content-Type: application/json и телом JSON.
6. **Какие HTTP-методы используются для управления заявками?** POST создаёт, GET читает, PUT редактирует, DELETE удаляет заявку.
7. **Для чего создаётся таблица requests?** В requests хранятся контакты, текст, статус и комментарий администратора.
8. **Что такое административная панель?** Админ-панель позволяет сотруднику просматривать и обрабатывать заявки.
9. **Для чего используется JWT?** JWT передаёт подписанные сервером сведения о роли и сроке действия сеанса.
10. **Почему необходимо проверять права администратора на сервере?** Клиент можно обойти прямым запросом. Сервер проверяет токен и роль на каждом административном маршруте.
