## Описание решения

```
Solution/
    schema.sql    девять таблиц из четвёртой работы, диалект MySQL 8
    data.sql      тестовые данные
    queries.sql   пятнадцать запросов
```

Данные я подбирал не случайно. В них специально есть модель без остатка ни в одном
размере, покупатель без единого заказа, модель без отзывов, отменённый заказ и две
снятые с продажи модели. Без этого половина запросов возвращала бы пустоту и проверить
их было бы нечем.

Запросы с первого по двенадцатый только читают данные, три последних меняют, поэтому
выполнять их надо в конце: после них результаты предыдущих запросов будут другими.

Последний запрос состоит из двух команд. Удалить отменённый заказ одной командой нельзя,
сначала внешний ключ `order_item` требует убрать позиции заказа.

## Как запустить

Сдавать можно и в базе, и в песочнице, методичка разрешает оба варианта.

В Workbench или OpenServer выполнить по очереди `schema.sql`, `data.sql`, `queries.sql`.
В онлайн-песочнице вроде sqliteonline или db-fiddle содержимое этих трёх файлов
вставляется в окно запроса в том же порядке.

Проверял я иначе: запросы прогоняются локально на SQLite скриптом, который переводит
объявления таблиц из диалекта MySQL и выполняет `queries.sql` как есть. Все шестнадцать
команд (пятнадцать запросов, последний из двух) проходят без ошибок.

## Теоретическая часть

SQL это язык запросов к реляционной базе. Условно он делится на несколько групп команд.
Выборку делает `SELECT`, изменение данных `INSERT`, `UPDATE` и `DELETE`, а структуру
таблиц описывают `CREATE TABLE` и `ALTER TABLE`.

Фильтрация идёт через `WHERE`, сортировка через `ORDER BY` с направлением `ASC` или
`DESC`, а `LIMIT` ограничивает число строк. Порядок важен: сначала отбираются строки,
потом сортируются, и только потом отрезается нужное количество, поэтому `ORDER BY` без
`LIMIT` даёт весь результат, а `LIMIT` без `ORDER BY` вернёт непредсказуемые строки.

Данные из нескольких таблиц соединяет `JOIN`. `INNER JOIN` оставляет только те строки, у
которых нашлась пара в обеих таблицах, `LEFT JOIN` сохраняет все строки левой таблицы, а
там, где пары нет, подставляет `NULL`. На этом построен двенадцатый запрос: покупатели
без заказов видны именно как строки с `NULL` в столбцах заказа.

Агрегатные функции считают значение по группе строк: `COUNT` количество, `SUM` сумму,
`AVG` среднее, `MIN` и `MAX` крайние значения. Работают они вместе с `GROUP BY`, который
делит выборку на группы. Отфильтровать сами группы `WHERE` уже не может, он отрабатывает
раньше группировки, для этого есть `HAVING`.

## Ответы на вопросы

**Что такое SQL?**

Язык структурированных запросов, с помощью которого создают структуру реляционной базы,
кладут в неё данные, изменяют их и получают обратно. Он декларативный: в запросе
описывается, какой результат нужен, а как его получить, решает сама СУБД.

**Для чего используется оператор SELECT?**

Для выборки данных. Он не меняет содержимое базы, а возвращает набор строк по описанным
условиям: какие столбцы нужны, из каких таблиц, с каким отбором, группировкой и
сортировкой.

**В чём разница между WHERE и ORDER BY?**

`WHERE` решает, какие строки попадут в результат, `ORDER BY` решает, в каком порядке они
выстроятся. Первый влияет на состав выборки, второй только на её вид. Выполняются они
тоже в этом порядке: сначала отбор, потом сортировка.

**Что делает оператор JOIN?**

Соединяет строки двух таблиц по условию, обычно по совпадению внешнего ключа с первичным.
Это позволяет собрать в одной выборке данные, которые при нормализации специально
разнесли по разным таблицам: например, название модели из `product` и название бренда из
`brand`.

**Как работает LIMIT?**

Ограничивает число строк в результате. Отрабатывает последним, уже после отбора,
группировки и сортировки, поэтому осмысленно применять его вместе с `ORDER BY`: иначе
непонятно, какие именно строки окажутся в выдаче.

**Какие операции выполняют INSERT, UPDATE и DELETE?**

`INSERT` добавляет новые строки, `UPDATE` меняет значения в существующих, `DELETE`
удаляет строки. У двух последних условие `WHERE` обязательно по смыслу: без него `UPDATE`
перепишет всю таблицу, а `DELETE` очистит её целиком.

**Что такое агрегатные функции?**

Функции, которые сворачивают несколько строк в одно значение: `COUNT` считает строки,
`SUM` складывает, `AVG` усредняет, `MIN` и `MAX` находят крайние значения. Без `GROUP BY`
они дают одно число по всей выборке, с ним по одному значению на каждую группу.
