# College Web-Programming

Практические работы по веб-программированию, 4 курс. Здесь лежат мои решения и разборы
заданий: от вёрстки статической страницы до базы данных под неё.

Каждое задание живёт в отдельной папке. Внутри исходная методичка `Task.docx`, папка
`Solution` с файлами решения и `README.md`, в котором разобрана теория, описано само решение
и даны ответы на контрольные вопросы.

## Задания

- [Task 1. Адаптивная вёрстка на HTML5 и CSS3](Task%201st%20Responsive%20Layout%20with%20HTML5%20and%20CSS3)
  Лендинг магазина кроссовок по макету из Figma: семантическая разметка, БЭМ, Flexbox,
  CSS Grid и адаптивность до 375 пикселей.

- [Task 2. Основы JavaScript](Task%202nd%20JavaScript%20Basics)
  Переменные, условия, циклы, функции, массивы и объекты. Одиннадцать небольших задач на
  базовый синтаксис.

- [Task 3. Интерактивность средствами JavaScript](Task%203rd%20DOM%20Interactivity%20with%20JavaScript)
  Работа с DOM и событиями поверх страницы из первой работы: модальное окно, бургер-меню,
  кнопка «наверх», аккордеон, переключение темы и галерея.

- [Task 4. Проектирование базы данных](Task%204th%20Database%20Design)
  ER-диаграмма и описание таблиц для предметной области сайта, нормализация до третьей
  нормальной формы.
