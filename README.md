# College Web-Programming

Практические работы по веб-программированию, 4 курс. Здесь лежат мои решения и разборы
заданий: от вёрстки статической страницы до базы данных под неё.

Каждое задание живёт в отдельной папке. Внутри исходная методичка `Task.docx`, папка
`Solution` с файлами решения и `README.md`, в котором разобрана теория, описано само решение
и даны ответы на контрольные вопросы.

## Задания

- [Task 1. Адаптивная вёрстка на HTML5 и CSS3](Task%201st%20Responsive%20Layout%20with%20HTML5%20and%20CSS3)
  Лендинг магазина кроссовок по макету из Figma: семантическая разметка, БЭМ, Flexbox,
  CSS Grid и адаптивность до 375 пикселей.

- [Task 2. Основы JavaScript](Task%202nd%20JavaScript%20Basics)
  Переменные, условия, циклы, функции, массивы и объекты. Одиннадцать небольших задач на
  базовый синтаксис.

- [Task 3. Интерактивность средствами JavaScript](Task%203rd%20DOM%20Interactivity%20with%20JavaScript)
  Работа с DOM и событиями поверх страницы из первой работы: модальное окно, бургер-меню,
  кнопка «наверх», аккордеон, переключение темы и галерея.

- [Task 4. Проектирование базы данных](Task%204th%20Database%20Design)
  ER-диаграмма и описание таблиц для предметной области сайта, нормализация до третьей
  нормальной формы.

- [Task 5. SQL-запросы](Task%205th%20SQL%20Queries)
  Пятнадцать запросов к базе магазина из четвёртой работы: выборка, сортировка,
  соединения, группировка с агрегатными функциями, добавление, изменение и удаление
  данных. Схема поднята в рабочую базу и наполнена тестовыми данными.

- [Task 6. Первый сервер на Node.js](Task%206th%20First%20Node.js%20Server)
  HTTP-сервер на встроенном модуле `http`: ответ браузеру на порту 3000 и второй вариант,
  который отдаёт название колледжа, фамилию и группу.

- [Task 7. Express.js и маршрутизация](Task%207th%20Express.js%20Routing)
  API каталога «Dream Sneakers» на Express: шесть маршрутов, три отдают текст и JSON по
  основному заданию, ещё три новости, рейтинг и категории по дополнительному.

## Как посмотреть базу пятой работы

В репозитории лежит `docker-compose.yml`, который поднимает MySQL 8 и Adminer. Нужен
только Docker.

```bash
docker compose up -d
```

Дальше открыть http://localhost:8081. Сервер `db`, пользователь `root`, пароль `root`,
база `dream_sneakers`. Схема и тестовые данные загружаются при первом запуске сами.

Запросы из `queries.sql` в базу автоматически не идут: их смысл в том, чтобы выполнять их
руками. Открываешь в Adminer вкладку SQL, вставляешь нужный запрос и смотришь результат.

Порты 3307 и 8081 выбраны так, чтобы не конфликтовать с репозиторием баз данных, который
занимает 3306 и 8080. Обе базы можно держать поднятыми одновременно.
