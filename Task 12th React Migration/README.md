## Теоретическая часть
React — популярная JavaScript-библиотека с открытым исходным кодом, созданная для разработки пользовательских интерфейсов. React позволяет разбивать интерфейс приложения на отдельные независимые части — компоненты. Используется JSX для описания структуры интерфейса внутри JavaScript-кода.

## Ответы на вопросы
1. Что такое React? — JavaScript-библиотека для разработки пользовательских интерфейсов.
2. Для чего используются компоненты? — Для разбиения интерфейса на отдельные независимые части.
3. Что такое JSX? — Синтаксис, позволяющий записывать структуру интерфейса внутри JavaScript-кода.
4. Чем JSX отличается от обычного HTML? — Использует className вместо class, поддерживает встроенные выражения в фигурных скобках.
5. Для чего используется className? — В JSX вместо атрибута class используется className.
6. Как создать React-проект с помощью Vite? — Выполнить `npm create vite@latest my-project`, выбрать React и JavaScript.
7. Для чего используется файл App.jsx? — Главный компонент, через который подключаются все остальные компоненты.
8. Для чего нужна папка components? — Для хранения пользовательских компонентов проекта.
