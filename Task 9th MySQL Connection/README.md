# Практическая работа №9. Подключение MySQL к Node.js

Первая работа курса, где данные берутся не из массива в памяти, а из базы. Сервер
подключается к MySQL драйвером `mysql2`, выполняет запрос и отдаёт результат. Плюс
дополнительные задания: маршрут только для RPG-игр и оформленная страница со списком.

## Как запустить

Нужна работающая база. В репозитории она поднимается тем же `docker-compose.yml`, что и в
пятой работе, скрипт девятой подключён к нему и выполняется при создании базы:

```bash
docker compose down -v
```

```bash
docker compose up -d
```

Дальше из папки `Solution`:

```bash
npm install
```

```bash
npm start
```

В консоли появятся две строки: «Сервер запущен» и «Подключение успешно». Вторая приходит
из `db.js` и означает, что соединение с базой установлено. Дальше открывается
http://localhost:3000.

Проверял на Node.js 24.14.0, Express 5.3.0, mysql2 3.24.6 и MySQL 8.

Если запускать не через Docker, а через OpenServer, как в методичке, в `db.js` меняются
два значения: порт на тот, что указан в настройках модуля MySQL, и пароль на пустой.
Остальное совпадает.

## Разбор кода

Подключение вынесено в отдельный модуль `db.js`. Там создаётся соединение и сразу
проверяется:

```js
connection.connect((err) => {
    if (err) {
        console.log("Ошибка подключения");
        return;
    }
    console.log("Подключение успешно");
});
```

Без этой проверки ошибка подключения всплыла бы только при первом запросе к маршруту, и
выглядела бы как ошибка сервера, а не как неверные параметры базы. Соединение
экспортируется один раз и переиспользуется всеми маршрутами: открывать его на каждый
запрос незачем.

Запрос выполняется методом `query`, результат приходит в функцию обратного вызова:

```js
db.query("SELECT * FROM games", (err, results) => {
    if (err) {
        return res.status(500).json({ error: err.message });
    }
    res.json(results);
});
```

Первым аргументом в обработчик всегда приходит ошибка, и проверять её надо до работы с
результатом. Обращение к базе асинхронное, поэтому ответ отправляется внутри функции
обратного вызова, а не после вызова `query`.

Страница лежит в папке `public` и отдаётся через `express.static`. Она запрашивает
`/games` и строит список из полученного JSON. Элементы создаются по отдельности, а текст
ставится через `textContent`, так что названия игр выводятся как текст.

Маршрут `/games/rpg` отличается от `/games` только условием в запросе. Жанр подставлен в
текст запроса константой, потому что он здесь не приходит от пользователя.

## Теоретическая часть

**MySQL** это реляционная система управления базами данных. Хранит информацию в связанных
таблицах, выполняет SQL-запросы и следит за целостностью данных.

**OpenServer** это сборка для локальной разработки, в которую входят Apache, Nginx, PHP и
MySQL. Через неё поднимают локальную базу и администрируют её из phpMyAdmin, не настраивая
каждый компонент отдельно.

**Драйвер** это библиотека, через которую программа общается с базой. Для Node.js и MySQL
это пакет `mysql2`: он открывает соединение по сети, отправляет текст запроса и
превращает ответ сервера в массив объектов JavaScript.

**Соединение** создаётся функцией `createConnection` с параметрами: адрес сервера, порт,
пользователь, пароль и имя базы. Пока соединение не установлено, запросы выполнять нельзя.

## Ответы на вопросы

**1. Что такое MySQL?**

Реляционная СУБД. Данные в ней хранятся в таблицах, связанных между собой, доступ к ним
идёт через SQL-запросы, а сама система следит за целостностью данных.

**2. Для чего используется OpenServer?**

Это набор программ для локальной разработки веб-приложений: веб-сервер, PHP и MySQL в
одной сборке. Позволяет поднять базу и сайт на своём компьютере без отдельной настройки
каждого компонента.

**3. Что такое mysql2?**

Пакет для Node.js, драйвер для работы с MySQL. Через него приложение подключается к базе,
отправляет запросы и получает результат в виде массива объектов.

**4. Для чего нужен createConnection()?**

Он создаёт объект соединения с базой по переданным параметрам: хост, порт, пользователь,
пароль и имя базы. Через этот объект потом выполняются все запросы.

**5. Что делает метод query()?**

Отправляет SQL-запрос серверу базы данных и возвращает результат. Работает асинхронно:
результат приходит не как возвращаемое значение, а в функцию обратного вызова, которой
первым аргументом передаётся ошибка, а вторым строки ответа.

**6. Что такое SQL-запрос?**

Команда на языке SQL, адресованная базе данных. Запросом выбирают, добавляют, изменяют и
удаляют данные, а также создают и меняют сами таблицы.

**7. Для чего используется SELECT?**

Для выборки данных из таблиц. В нём указывают, какие столбцы вернуть, из какой таблицы и
при каком условии.

**8. Как подключиться к базе данных?**

Установить драйвер (`npm install mysql2`), создать соединение через `createConnection` с
параметрами базы и вызвать `connect`. После успешного подключения через полученный объект
выполняются запросы.
