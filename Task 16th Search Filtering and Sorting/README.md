# ПР №16. Поиск, фильтрация и сортировка

Каталог ищет по названию, фильтрует по категории и наличию и сортирует по цене или названию в обе стороны. Параметры применяются вместе. Сброс очищает поиск, возвращает все категории, отключает фильтр наличия и ставит цену по возрастанию.

## Как запустить

Нужны Node.js 22.12 или новее и Docker. Из корня CollegeWebProgramming запустить:

```powershell
docker compose up -d --wait
docker compose exec -T db mysql --default-character-set=utf8mb4 -uroot -proot -e "source /docker-entrypoint-initdb.d/17-dream-sneakers.sql"
```

При первом запуске MySQL создаёт таблицы автоматически. Вторая команда добавляет
их в уже существующую базу и сохраняет данные. Adminer: http://localhost:8081,
сервер `db`, учебный логин `root` и пароль `root`, база `dream_sneakers`.

В папке `Solution` скопировать `.env.example` в `.env`. Подключение уже настроено
на MySQL из Docker (`127.0.0.1:3307`). Заполнить `ADMIN_PASSWORD` для входа в панель
и задать случайный `JWT_SECRET` длиной от 32 символов.

~~~powershell
npm ci
npm run server
~~~

В другом окне, из той же папки:

~~~powershell
npm run dev
~~~

Открыть адрес Vite. Панель заявок находится на /admin. Для проверки сборки
выполнить npm run build.

## Проверка

Выбрать «Беговые», включить «Только в наличии» и ввести night. Останется Night Runner. Ввести zzz, проверить пустую выдачу и нажать «Сбросить».

## Контрольные вопросы

1. **Для чего используются поиск, фильтрация и сортировка?** Поиск находит запись по тексту, фильтр отбирает по условиям, сортировка задаёт порядок.
2. **Чем отличаются методы filter() и sort()?** filter возвращает новый массив подходящих элементов. sort меняет порядок элементов массива, поэтому сортируется копия.
3. **Для чего используется useState() в React?** useState хранит запрос, фильтры и направление сортировки между рендерами.
4. **Чем отличаются ref() и computed() во Vue?** ref хранит реактивное значение. computed пересчитывает производное значение при изменении зависимостей.
5. **Для чего используется директива 'use client' в Next.js?** Директива помечает точку входа клиентских компонентов Next.js, в которых доступны состояние и обработчики событий.
6. **Чем отличаются клиентская и серверная фильтрация?** Клиентская обработка работает с уже полученным массивом. Серверная ограничивает данные до передачи клиенту.
7. **Для чего используются параметры запроса URL?** Параметры URL передают значения поиска, фильтров и сортировки серверу или позволяют сохранить состояние ссылки.
8. **Что такое пагинация и в каких случаях она необходима?** Пагинация делит выдачу на страницы. Она нужна, когда полный список дорого передавать или отображать.
