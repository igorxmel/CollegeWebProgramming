# ПР №17. Основная функциональность Fullstack-проекта

Каталог читает товары из MySQL через API. Покупатель кладёт модели в корзину, меняет количество и оформляет заказ. Сервер принимает идентификаторы и количество, проверяет наличие, берёт цену из базы и одной транзакцией сохраняет заказ с позициями.

## Как запустить

Нужны Node.js 22.12 или новее и MySQL. На колледжном ПК открыть phpMyAdmin
в Open Server Panel и выполнить Solution/schema.sql на вкладке SQL.
Скрипт создаёт необходимые таблицы в dream_sneakers.

В папке Solution скопировать .env.example в .env. Указать пользователя,
пароль и порт MySQL из Open Server Panel. Задать пароль ADMIN_PASSWORD
для входа в панель и случайный JWT_SECRET длиной от 32 символов.

~~~powershell
npm ci
npm run server
~~~

В другом окне, из той же папки:

~~~powershell
npm run dev
~~~

Открыть адрес Vite. Панель заявок находится на /admin. Для проверки сборки
выполнить npm run build.

## Проверка

Добавить Urban Classic, увеличить количество до двух, проверить сумму 12 980 ₽. Ввести имя и телефон. После оформления убедиться, что корзина очищена, а в shop_orders и shop_order_lines появились записи.

## Контрольные вопросы

1. **Что такое бизнес-логика веб-приложения?** Бизнес-логика описывает правила предметной области. В магазине она определяет допустимое количество, наличие, расчёт цены и сохранение заказа.
2. **Как взаимодействуют клиентская и серверная части Fullstack-приложения?** Клиент показывает интерфейс и посылает HTTP-запрос. Сервер выполняет правила, работает с БД и возвращает JSON.
3. **Для чего используется useState() в React?** useState хранит значения, меняющиеся после действий пользователя, например корзину.
4. **Как работают ref() и reactive() во Vue?** ref связывает реактивное значение с интерфейсом, а reactive делает реактивным объект.
5. **Чем серверные компоненты Next.js отличаются от клиентских?** Серверные компоненты исполняются на сервере и могут получать данные там. Клиентские обеспечивают интерактивность и используют состояние.
6. **Для чего используется Fetch API?** Fetch API выполняет HTTP-запросы и даёт прочитать ответ, в том числе JSON.
7. **Почему проверка данных должна выполняться на сервере?** Сервер получает данные из любого клиента, поэтому сам проверяет количество, наличие и формат контактов.
8. **Как происходит сохранение и получение данных из базы MySQL?** Express выполняет параметризованные SELECT и INSERT через mysql2. Транзакция сохраняет заказ и строки вместе.
